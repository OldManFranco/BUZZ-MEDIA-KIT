## Strategist spec (verbatim)

**Format change:** motivational-speech-over-highlights → 90-second athlete micro-documentaries with a factual hook and motivational payoff.

**Hook rule (strict):** First 2 seconds must contain a factual, surprising, specific claim with at least one proper noun + one specific detail (number, place, date, situation). The agent MUST reject any hook that doesn't meet this bar.

Good examples:
- "Michael Jordan played baseball in Birmingham for $850 a month."
- "JJ Watt broke his hand in week 2 and still led the league in sacks."
- "Jon Jones failed a USADA test the day before his biggest fight."

Bad examples:
- "Limits are an illusion."
- "He proved them all wrong."

**3 hook variants per video**, presented for human review. Only human-in-the-loop checkpoint for hook; everything else is autonomous.

**Target length:** 90 seconds (1:00 minimum, 1:30 ideal). Longer unlocks higher Creator Rewards payouts.

**Structural beats:**
- 0:00–0:02 — Hook claim
- 0:02–0:15 — Scene set (where, when, stakes)
- 0:15–0:50 — Story unfolds (challenge, twist, what they did)
- 0:50–1:15 — Result + short real-speech clip from athlete as emotional punctuation at the climax
- 1:15–1:30 — Lesson / motivational payoff ("The Standard" brand lands here)

**Narration/speech ratio flipped:**
- OLD: ~5s ElevenLabs narration + ~55s speech audio
- NEW: ~60–70s ElevenLabs narration (Declan Sage carries the story) + ~15–20s real speech used only as emotional punctuation at climax

**Agent handles story research autonomously:**
- Given an athlete's name
- Research + identify specific lesser-known story with motivational arc (challenge → response → outcome → lesson)
- Prioritize non-obvious stories (not Jordan's flu game, not Kobe's 81)
- Verify facts across ≥2 sources before writing
- Write 150–200 word script following the 5-beat structure
- Produce 3 hook variants

**Scene pack sourcing changes:**
- Story-specific archival footage, not generic highlights
- If story is Jordan's baseball year: Birmingham Barons footage, not Bulls highlights

**US audience signals:**
- US-coded hashtags (#nba #nfl #mambamentality #goat #sportshighlights + athlete-specific)
- Trending US sounds as music bed
- US-specific context references in narration

**Stays locked from v2.4:**

- Text overlay style: all caps, soft dark halo, fixed screen position
- Per-video folder structure (/Speech/, /Scene Pack/, /Music/, /Narration/)
- English only
