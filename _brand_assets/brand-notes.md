# Buzz Media brand notes (for the editing kit)

Source: `Buzz-Media-Brand-Kit.pdf` (Brand Guidelines v1.0, October 2026). This file turns it into values the pipeline uses. When the PDF and this file disagree, the PDF wins; fix this file.

## 1. Logo

- Icon: a red "recording light" circle with a white **B**. Always left of the wordmark, cap height. Clear space = icon width.
- Wordmark: **Buzz** (ExtraBold) **Media** (Regular).
- On yellow, the dot turns ink. Never stretch, rotate, outline, shadow or gradient it. On busy footage, only on a dark band.
- No logo file (SVG/PNG) is in the kit yet. Ask Franco before rebuilding it from the PDF.

## 2. Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#121212` | Type, dark backgrounds, reel end cards |
| Paper | `#F4F1EA` | Light backgrounds, documents |
| **Buzz Yellow** | `#FFC629` | **The one accent:** a key word, a tag, a thin line |
| Record Red | `#D7263D` | The logo dot only. Never a background, never a caption highlight |
| Stone | `#6B6B6B` | Captions in documents, fine print, source lines |

Balance: mostly paper and ink, yellow sparingly so it always means "look here".

## 3. Type

- **Schibsted Grotesk:** headlines ExtraBold 800, tight tracking, **sentence case always**; body Regular 400.
- **IBM Plex Mono:** labels, prices, numbers, timecodes. Labels uppercase with wide tracking (e.g. `STRATEGY · FILM · EDIT`, `PLANS FROM $199/MO`).
- Both are free on Google Fonts (OFL). **Not on this machine yet.** They need downloading into `_brand_assets\fonts\` (Franco's OK first).

## 4. Reel captions (Buzz Media's own reels)

From the brand kit's "Reel · hook and captions" mockup, adapted to the kit's caption rules (CLAUDE.md §7):

- Schibsted Grotesk ExtraBold, white, sentence case (not uppercase: brand rule), soft drop shadow for legibility on footage.
- Active word: **Buzz Yellow** text (or a yellow plate with ink text for the hook line). Never green, never red.
- 3–4 words on screen max, centered, inside the phone-safe zone.
- Hook text at the top (y ≈ 300–600), Schibsted ExtraBold, one yellow phrase on a yellow plate (mockup: "Your competitor posts **every day**").
- Small red B icon top-right is in the mockup. Treat it as optional and ask; the kit's default is no watermark.

## 5. End card

From the mockup: ink background, red B icon, "Comment **EDIT**" (EDIT in yellow) in Schibsted ExtraBold, `PLANS FROM $199/MO` below in Plex Mono uppercase, tracked.

## 6. Voice (for titles, captions, package copy)

Lead with results (numbers first). Plain and direct, short sentences, no hype words, no emojis. Warm, not salesy. Always one clear next step.
Tagline, used exactly as written: **Strategy. Film. Edit.**
Say: "We edited 200+ videos this year. Send us your raw clips and you'll have reels back in 48 hours."
Don't say: "elevate your brand", "unlock viral growth", "game-changing".
